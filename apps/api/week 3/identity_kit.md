## 🔤 1. Typography Selection

* **Heading Font:** `Plus Jakarta Sans` (Bold 700 / SemiBold 600)  
  * *Rationale:* Clean, modern geometric sans-serif that conveys technical precision without feeling sterile.
* **Body Font:** `Inter` (Regular 400 / Medium 500)  
  * *Rationale:* Industry-standard legibility for technical documentation, code snippets, and case study narratives.
