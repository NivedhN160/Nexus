# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-01

### Added
- **OpenWakeWord Integration**: True non-blocking continuous listening.
- **Persistent Knowledge Graph**: SQLite + ChromaDB hybrid memory indexing for both user and assistant interactions.
- **Proactive Daemon Loop**: Background thread for autonomous fact extraction and idle triggers.
- **Holographic GUI**: PyQt6 3D rotating UI with audio-reactive waveform visualizer.
- **Deterministic Tool Calling**: Hardened regex parsing for native Python code execution and system API interactions.
- **CI/CD Pipeline**: Automated GitHub Actions for flake8 linting and pytest testing.

### Changed
- Refactored entire codebase to use structured Python `logging` instead of `print()`.
- Renamed project identity to N.E.O.S (Neural Executive Operating System).
